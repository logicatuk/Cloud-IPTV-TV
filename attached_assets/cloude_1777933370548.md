## 0. What We Are Building

MaxPlayer is a **SaaS IPTV platform** modeled after IBO Player's activation system, with the content experience of nodecast-tv (Live TV + EPG + Movies + Series), delivered as:

| Layer | What | Tech |
|-------|------|------|
| **CMS Panel** | Super Admin + Reseller web dashboard | React 18 + Vite + Ant Design 5 |
| **Backend API** | All business logic + Xtream proxy | Node.js 20 + Express 4 + PostgreSQL 16 |
| **Flutter App** | End-user player (Android, iOS, FireStick) | Flutter 3.x + Riverpod 2 + better_player |
| **Samsung TV** | Tizen web app | HTML5 + Vanilla JS + AVPlay |
| **LG TV** | webOS web app | HTML5 + Vanilla JS + Luna |
| **Web Player** | Browser player (optional phase 2) | React + HLS.js |

## 1. Business Model — The Three Tiers

```
YOU (Super Admin)
│  Panel: admin.maxplayer.com
│  • Create reseller accounts
│  • Sell credits to resellers (1 credit = 1 device license)
│  • Add IPTV servers (host + username + password)
│  • Monitor everything globally
│
├── RESELLER (Admin)
│   Panel: admin.maxplayer.com (same panel, different role/scope)
│   • Log in with email + password
│   • See their credit balance
│   • Activate devices by MAC address (costs 1 or 2 credits)
│   • Assign playlist (M3U URL or Xtream credentials) to each device
│   • Renew, suspend, delete devices
│   • Optionally create sub-resellers (if super admin enabled this)
│
└── END USER (Viewer)
    App: MaxPlayer (Android / iOS / Samsung / LG)
    • Open app → sees their MAC address + device key on screen
    • Gives MAC to reseller → reseller activates in panel
    • App auto-detects activation → shows content immediately
    • Streams Live TV, Movies, Series from their assigned playlist
    • No manual URL entry — playlist is assigned from the panel
```

### Credit System
| Tier | Credits Used |
|------|-------------|
| 1 Year license | 1 credit |
| 2 Year license | 2 credits |
| Lifetime license | 3 credits |
| Renewal +1 Year | 1 credit |

## 3. Database Schema — Every Table, Every Column

```sql
-- ══════════════════════════════════════
-- USERS (super admin + resellers)
-- ══════════════════════════════════════
CREATE TABLE users (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email           VARCHAR(255) UNIQUE NOT NULL,
  password_hash   VARCHAR(255) NOT NULL,
  name            VARCHAR(255) NOT NULL,
  role            VARCHAR(20) NOT NULL CHECK (role IN ('superadmin','reseller')),
  parent_id       UUID REFERENCES users(id),  -- reseller's parent (superadmin or reseller)
  credit_balance  INTEGER NOT NULL DEFAULT 0,
  max_devices     INTEGER NOT NULL DEFAULT 100,
  status          VARCHAR(20) NOT NULL DEFAULT 'active' CHECK (status IN ('active','suspended')),
  notes           TEXT,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW(),
  last_login_at   TIMESTAMP
);

-- ══════════════════════════════════════
-- IPTV SERVERS (managed by super admin)
-- ══════════════════════════════════════
CREATE TABLE iptv_servers (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name            VARCHAR(255) NOT NULL,
  host            VARCHAR(500) NOT NULL,        -- http://provider.com:8080
  username        VARCHAR(255) NOT NULL,
  password_enc    VARCHAR(500) NOT NULL,        -- AES-256 encrypted
  status          VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active','inactive')),
  max_connections INTEGER DEFAULT 1000,
  notes           TEXT,
  last_checked_at TIMESTAMP,
  is_online       BOOLEAN DEFAULT true,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW()
);

-- ══════════════════════════════════════
-- DEVICES (end user TV/phone/stick)
-- ══════════════════════════════════════
CREATE TABLE devices (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mac_address     VARCHAR(17) UNIQUE NOT NULL,  -- format: aa:bb:cc:dd:ee:ff
  name            VARCHAR(255),                 -- optional label by reseller
  reseller_id     UUID NOT NULL REFERENCES users(id),
  license_tier    VARCHAR(20) NOT NULL CHECK (license_tier IN ('1year','2year','lifetime')),
  credits_used    INTEGER NOT NULL,             -- 1, 2, or 3
  status          VARCHAR(20) NOT NULL DEFAULT 'active' CHECK (status IN ('active','suspended','expired')),
  activated_at    TIMESTAMP,
  expires_at      TIMESTAMP,                   -- NULL = lifetime
  registered_at   TIMESTAMP DEFAULT NOW(),     -- when device first called our API
  last_seen_at    TIMESTAMP,
  notes           TEXT,
  created_at      TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW()
);

-- ══════════════════════════════════════
-- PLAYLISTS (assigned to each device)
-- ══════════════════════════════════════
CREATE TABLE playlists (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id       UUID UNIQUE REFERENCES devices(id) ON DELETE CASCADE,
  type            VARCHAR(10) NOT NULL CHECK (type IN ('m3u','xtream')),
  -- M3U fields
  m3u_url         VARCHAR(1000),
  -- Xtream fields
  xtream_host     VARCHAR(500),
  xtream_username VARCHAR(255),
  xtream_password_enc VARCHAR(500),             -- AES-256 encrypted
  -- common
  server_id       UUID REFERENCES iptv_servers(id), -- optional: link to managed server
  assigned_at     TIMESTAMP DEFAULT NOW(),
  updated_at      TIMESTAMP DEFAULT NOW()
);

-- ══════════════════════════════════════
-- CREDIT TRANSACTIONS
-- ══════════════════════════════════════
CREATE TABLE credit_transactions (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES users(id),
  type            VARCHAR(20) NOT NULL CHECK (type IN ('purchase','debit','refund','gift')),
  amount          INTEGER NOT NULL,             -- positive = added, negative = used
  balance_after   INTEGER NOT NULL,
  reference       VARCHAR(255),                 -- device MAC or order ID
  notes           TEXT,
  created_by      UUID REFERENCES users(id),   -- who performed the action
  created_at      TIMESTAMP DEFAULT NOW()
);

-- ══════════════════════════════════════
-- REFRESH TOKENS
-- ══════════════════════════════════════
CREATE TABLE refresh_tokens (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  device_id       UUID REFERENCES devices(id), -- for device (app) tokens
  token           VARCHAR(500) UNIQUE NOT NULL,
  expires_at      TIMESTAMP NOT NULL,
  revoked         BOOLEAN DEFAULT false,
  created_at      TIMESTAMP DEFAULT NOW()
);

-- ══════════════════════════════════════
-- STREAM TOKENS (short-lived, per stream)
-- ══════════════════════════════════════
CREATE TABLE stream_tokens (
  token           VARCHAR(64) PRIMARY KEY,
  device_id       UUID NOT NULL REFERENCES devices(id),
  stream_type     VARCHAR(10) NOT NULL CHECK (stream_type IN ('live','movie','episode')),
  stream_id       VARCHAR(100) NOT NULL,        -- Xtream stream ID
  expires_at      TIMESTAMP NOT NULL,           -- max 4 hours
  ip_address      VARCHAR(45),
  created_at      TIMESTAMP DEFAULT NOW()
);

-- ══════════════════════════════════════
-- WATCHLIST (per device)
-- ══════════════════════════════════════
CREATE TABLE watchlist (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id       UUID NOT NULL REFERENCES devices(id),
  item_type       VARCHAR(10) NOT NULL CHECK (item_type IN ('live','movie','series')),
  item_id         VARCHAR(100) NOT NULL,        -- Xtream stream/vod/series ID
  item_name       VARCHAR(500),
  item_poster     VARCHAR(1000),
  added_at        TIMESTAMP DEFAULT NOW(),
  UNIQUE(device_id, item_type, item_id)
);

-- ══════════════════════════════════════
-- WATCH HISTORY + RESUME POSITION
-- ══════════════════════════════════════
CREATE TABLE watch_history (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id       UUID NOT NULL REFERENCES devices(id),
  item_type       VARCHAR(10) NOT NULL CHECK (item_type IN ('live','movie','episode')),
  item_id         VARCHAR(100) NOT NULL,
  series_id       VARCHAR(100),                 -- if episode: parent series ID
  item_name       VARCHAR(500),
  item_poster     VARCHAR(1000),
  position_seconds INTEGER DEFAULT 0,           -- resume point
  duration_seconds INTEGER DEFAULT 0,
  completed       BOOLEAN DEFAULT false,        -- watched >= 90%
  watched_at      TIMESTAMP DEFAULT NOW(),
  UNIQUE(device_id, item_type, item_id)
);

-- ══════════════════════════════════════
-- AUDIT LOG
-- ══════════════════════════════════════
CREATE TABLE audit_logs (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  actor_id        UUID,                         -- user who did the action
  actor_role      VARCHAR(20),
  action          VARCHAR(100) NOT NULL,        -- 'device.activate', 'reseller.create', etc.
  entity_type     VARCHAR(50),
  entity_id       UUID,
  payload         JSONB,
  ip_address      VARCHAR(45),
  created_at      TIMESTAMP DEFAULT NOW()
);

-- INDEXES
CREATE INDEX idx_devices_mac ON devices(mac_address);
CREATE INDEX idx_devices_reseller ON devices(reseller_id);
CREATE INDEX idx_devices_status ON devices(status);
CREATE INDEX idx_watch_history_device ON watch_history(device_id);
CREATE INDEX idx_watchlist_device ON watchlist(device_id);
CREATE INDEX idx_stream_tokens_token ON stream_tokens(token);
CREATE INDEX idx_audit_logs_actor ON audit_logs(actor_id);
```

## 11. Security Rules — Non-Negotiable

1. **IPTV credentials NEVER leave the backend.** No hostname, no username, no password in any API response to the app or panel.
2. **Stream URLs are signed tokens.** Generated by backend, short-lived (4h), IP-bound. Format: `/stream/{64-char-token}.m3u8`
3. **MAC address is the device identity.** Validate format on every input: `/^([0-9A-Fa-f]{2}:){5}[0-9A-Fa-f]{2}$/`
4. **Device tokens** are separate from admin panel tokens. Device JWT payload: `{ device_id, mac_address, type: 'device' }`. Admin JWT: `{ user_id, role, type: 'admin' }`.
5. **bcrypt** for all passwords. Salt rounds: 12.
6. **AES-256-GCM** for IPTV passwords stored in DB. Key from `ENCRYPTION_KEY` env var.
7. **Rate limiting**: 10 req/min on `/device/register`, 60/min on content routes, 10/min on admin auth.
8. **License check on every content request.** If device status = expired/suspended → 403.
9. **Credit atomicity.** Credit deduction and device activation must be in a single DB transaction. If activation fails → rollback credits.
10. **Audit every action.** Every activate/renew/suspend/create-reseller must write to `audit_logs`.
11. **Redis cache keys** always include the Xtream username to isolate per-device data.

```javascript
// New service: services/tmdb.service.js
class TMDBService {
  constructor(apiKey) {
    this.base = 'https://api.themoviedb.org/3';
    this.key = apiKey;
  }

  async getMovieDetails(tmdbId) {
    const cacheKey = `tmdb:movie:${tmdbId}`;
    // cache 24h
    return axios.get(`${this.base}/movie/${tmdbId}?api_key=${this.key}`);
  }

  async getMovieCredits(tmdbId) {
    return axios.get(`${this.base}/movie/${tmdbId}/credits?api_key=${this.key}`);
  }

  async getMovieVideos(tmdbId) {
    // filter for type=Trailer, site=YouTube
    return axios.get(`${this.base}/movie/${tmdbId}/videos?api_key=${this.key}`);
  }

  async getSeriesDetails(tmdbId) {
    return axios.get(`${this.base}/tv/${tmdbId}?api_key=${this.key}`);
  }

  getPosterUrl(path, size = 'w500') {
    return `https://image.tmdb.org/t/p/${size}${path}`;
  }

  getBackdropUrl(path) {
    return `https://image.tmdb.org/t/p/original${path}`;
  }
}
```

### 19.8 Confirmed Auto-Update Logic (ibopro behavior)

```dart
// ibopro SharedPreferences keys (map to Hive in Flutter):
// 'auto_update_everyday'   → refresh on every daily launch
// 'auto_update_2day'       → refresh every 48 hours
// 'auto_update_everytime'  → refresh on EVERY app open

// Implementation in Flutter:
class ContentRefreshService {
  static Future<bool> shouldRefresh(AutoUpdateInterval interval) async {
    final box = Hive.box('settings');
    final lastRefresh = box.get('last_refresh') as DateTime?;
    if (lastRefresh == null) return true;
    
    switch (interval) {
      case AutoUpdateInterval.everyTime:  return true;
      case AutoUpdateInterval.daily:      return DateTime.now().difference(lastRefresh).inHours >= 24;
      case AutoUpdateInterval.every2Days: return DateTime.now().difference(lastRefresh).inHours >= 48;
    }
  }
  
  static Future<void> markRefreshed() async {
    await Hive.box('settings').put('last_refresh', DateTime.now());
  }
}
```
